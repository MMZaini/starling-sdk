# Changelog

## 0.1.0

- TypeScript and Python clients for all 87 Starling Public API operations.
- Explicit OAuth code exchange and rotating refresh-token helpers, including mutual TLS.
- RSA-SHA512 request signing and V2 webhook verification.
- Feed iterators, binary uploads/downloads and accepted attachment-response handling.
- Separate React account cards, masked identifiers and exact money formatting.
- Pinned Fern generation, sandbox smoke checks and npm/PyPI release automation.
